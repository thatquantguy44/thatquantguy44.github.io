## Verification performed

- Sixty-one trading-package tests pass, including the offline pipeline and local timestamp extensions. The existing agent package's 34 tests passed in the preceding package validation; that code has not changed.
- Synthetic opportunity → prediction → outcome appends succeed with ordered references, a checked hash chain, and an explicit target label. Invented prices, identifiers, and injected clocks exist only in the software tests and are not research observations.
- Future outcomes, source/feature timestamp inconsistencies, model execution before opportunity registration, duplicate IDs, duplicate original issuer/period events, replacement predictions/outcomes, and outcome fields inside a forecast are rejected.
- Late/failed forecasts, unknown costs, and request/cost/deadline violations remain visible with classifications rather than being silently replaced or counted as valid forecasts.
- Corrections append annotations without overwriting previous observations. Changed record contents and changed manifest contents are detected against the retained chain. Concurrent writers preserve all eight independently identified records in the concurrency check.
- Brier losses, sentiment smoothing, momentum clipping, cash behavior, and both proportional transaction charges are checked. The cost check independently recomputes initial stock notional and exit proceeds using decimal arithmetic.
- A fresh development session initializes with zero events, verifies successfully, and never reports independently verified timing. An unbound prospective session is rejected before its directory is created. Existing sessions cannot be overwritten.
- The schema generated by the CLI matches the committed schema. Cross-record/time checks are intentionally separate from JSON Schema field validation.
- End-to-end CLI checks ran in temporary directories: readiness, synthetic pipeline, local ledger verification, and nonce-bearing timestamp request generation without submission. No actual model requests, broker calls, market-data downloads, forecasts, price observations, or live sessions were created by these checks.
- The synthetic pipeline succeeds with Python socket creation and DNS resolution disabled. It also retains invalid mock model output as a failed forecast without losing the other three baseline conditions.
- Additional checks cover DST, early closes, duplicate/overlapping core sessions, missing/zero-volume/duplicate minute bars, feed mismatch, future/as-of momentum inputs, toy dictionary counts, literal evidence, and unsupported corporate actions.
- Local timestamp tests use a temporary untrusted CA/TSA to verify signatures against a pinned root file, matching ledger digest and request nonce, and a cutoff/error-bound rule. A different digest, different nonce, wrong root-file pin, or post-cutoff signed time fails. Generated private keys remain temporary; no external service or actual trust anchor is authenticated by these tests.

## Material limits

- A local clock/hash chain is not trusted timestamping. The utility always reports independent timing as unverified. Full-chain rewriting or truncation requires an independently retained head/receipt to detect; no such service is connected here.
- Source hashes and evidence references are recorded assertions until their original artifacts are audited. The logger does not retrieve documents or authenticate source publication times, exchange calendars, licensing rights, price feeds, or corporate-action calculations.
- Source-time and prospective-session configuration checks validate recorded fields, not the truth of the operator's assertions. Synthetic filled bindings in tests are not provider-readiness proof.
- Pure local adapters now implement input normalization, dictionary tokenization, supplied-calendar window selection, matching as-of momentum levels, strict minute-VWAP aggregation, model-output validation, and price-only returns for explicitly verified no-action cases. The full collector, actual model/vendor transports, financial-dictionary acquisition/permissions, calendar completeness, and real corporate-action/total-return adapters remain unimplemented or unverified. Synthetic attestations are not source authentication.
- Cohort membership, permitted dictionary use, precise model/prices, 42-day collection dates, and trusted receipt method remain unbound. No real prospective series has started.
- The proposed six-week window checks the collection process; it is not an assurance of sample size, statistical power, usable calibration, or durable alpha. Dependence-aware main-study inference and any self-financing portfolio require additional frozen design work.
